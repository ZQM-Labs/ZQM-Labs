![Languages](https://github-readme-stats.vercel.app/api/top-langs/?username=ZQM-Labs&layout=compact&theme=default&hide_border=true&hide=Jupyter+Notebook)

## About

ZQM-Labs is the research and development arm of ZQM Computing. We build open-source tooling for:

- Windows attestation and compliance automation
- Security orchestration and incident response
- AI-assisted code review and agent frameworks
- PQC readiness and cryptographic hygiene

All repos are MIT-licensed. See [ZQM-Computing](https://github.com/ZQM-Computing) for production services.
